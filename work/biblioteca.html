Gestión de Biblioteca

Aplicación de escritorio para registrar, buscar, modificar y eliminar libros, autores y disponibilidad mediante operaciones CRUD y conexión a MySQL.

Año2024
EstadoCompletado
TipoAplicación de escritorio
StackJava Swing · MySQL · POO

01 / Contexto

Problema y enfoque

El proyecto busca centralizar el registro y la consulta de libros, autores y disponibilidad en una aplicación de escritorio, evitando depender de registros dispersos.

Se construyó una aplicación con interfaz Java Swing, operaciones CRUD, programación orientada a objetos y conexión a MySQL. Las pantallas disponibles muestran dashboard, listado de libros y formulario de gestión.

02 / Alcance

Qué se documentó
