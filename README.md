# JRCholan Portfolio — Editorial Edition

Portafolio personal estático listo para GitHub Pages.

## Dirección visual
- Estética editorial técnica, sin gradientes morados, glassmorphism ni UI de plantilla.
- Instrument Serif + IBM Plex Sans + IBM Plex Mono.
- Paleta cálida y sobria con un acento terracota.
- Tres case studies principales y archivo secundario.

## Estructura
- `index.html` — home
- `work/` — casos de estudio
- `assets/css/styles.css` — sistema visual
- `assets/js/main.js` — navegación, reveal, scroll spy y copiar email
- `assets/images/` — imágenes optimizadas WebP
- `assets/docs/` — CV y certificados

## Publicar
El proyecto incluye `CNAME` para `jrcholan.lat` y funciona como sitio estático en GitHub Pages.
